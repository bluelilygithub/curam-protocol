QUICK DEPLOYMENT (3 STEPS)
================================================================================

1️⃣  BACKUP CURRENT PLUGIN
   cd wp-content/plugins/
   tar -czf curam-backup-$(date +%Y%m%d).tar.gz curam-ai-xero/

2️⃣  REPLACE FILES
   rm -rf curam-ai-xero/
   mv curam-xero-refactored/ curam-ai-xero/

3️⃣  ACTIVATE & TEST
   - Go to Plugins → Installed Plugins
   - Activate "Curam-Ai Xero Integration"
   - Visit Dashboard → Xero to verify

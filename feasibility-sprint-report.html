The Three Tests: What We Validate

Every Phase 1 sprint validates technical feasibility through three mandatory tests. All three must pass to proceed to Phase 2.

Test 1: Field Extraction Accuracy

Question: Can AI accurately extract the required fields from YOUR document formats?

✅ Success Criteria:
  • ≥90% overall accuracy across all fields
  • Critical fields (IDs, amounts, dates) >95%
  • Low-confidence fields properly flagged
❌ Failure Indicators:
  • <90% accuracy = System unreliable
  • Critical fields consistently missed
  • Document format/complexity too high

Test 2: Straight-Through Processing Rate

Question: What % of documents can be processed with ZERO human intervention?

✅ Success Criteria:
  • ≥60% STP rate (varies by industry)
  • Consistent pattern across categories
  • Remaining docs properly routed to review
❌ Failure Indicators:
  • <40% STP = Too many exceptions
  • Inconsistent across document types
  • Automation ROI insufficient

Test 3: Exception Handling & Safety

Question: Does the system fail safely when encountering ambiguous data?

✅ Success Criteria:
  • Genuine exceptions correctly identified
  • Low false positive rate
  • Safe fail-over to human review
❌ Failure Indicators:
  • High false positive (over-flags valid data)
  • Missed exceptions (risky automation)
  • Inconsistent edge case handling

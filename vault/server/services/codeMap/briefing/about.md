Vault (Curam Vault) is an invite-based, multi-user AI workspace: one web app holding about sixty tools for running a small business and the owner's own work, from notes, tasks, chat and a CRM to finance, shares, document tools, SEO and site tools, planners and personal tools.
Who uses it: the owner (the first user, an admin) and a few invited members. Public sign-up is closed; admins create accounts. Accountant logins see only Finance (and Shares if allowed). Each tool can be switched off for the workspace or narrowed per member.
Server: Node.js with Express, raw parameterised SQL through `pg` (no ORM), PostgreSQL 15 with pgvector. The schema is idempotent DDL in `server/db.js`, run on every boot; there is no migration tool.
Client: React 18 with Vite, Zustand stores, React Router v6, Tailwind for layout only (colours come from six theme CSS variables). One navigation catalog (`client/src/config/appNavigation.js`) feeds the menu, sidebar, top bar and Ctrl+K.
Auth: random session tokens in `auth_sessions`, checked on every request (not JWT). `/api/*` is behind `requireAuth`; admin routes behind `requireAdmin`; feature routes behind `requireFeature`.
AI: Anthropic Claude is primary, Google Gemini secondary (and embeddings for RAG). Model ids are never hardcoded: they come from Settings through `getModelsForUser()` (`standard` for real work, `light` for cheap background calls). Chat streams over SSE with prompt caching.
Background work: node-cron jobs (mail, digests, syncs, purges) wrapped in `withCronLock` when they send mail, create records or call paid APIs; longer jobs run as background jobs or worker threads.
Findings from services and crons go to one Suggestions inbox (`SuggestionService`) rather than only the log. Deletes go to a shared 30-day recycle bin.
Hosting: Railway, one service, deployed by pushing the `version-7` branch. The slow layers (system packages, Chromium for Playwright, Python tools, node_modules) are a base image built by GitHub Actions into GHCR only when dependencies change, so a normal deploy takes 2-3 minutes; editing package.json triggers a 10-15 minute rebuild.
Every commit gets an entry in the admin Changelog, and an admin Code Map checks every tool against the house rules weekly.
